# CAPACITI Candidate Management System

A responsive web application prototype designed to support the management of CAPACITI candidates, attendance, daily activities, work-from-home requests, and performance assessments.

## Project Overview

The CAPACITI Candidate Management System provides separate portals for Candidates, Mentors, and Administrators.

The system is designed to simplify candidate monitoring and provide a central platform where candidates can record their daily activities while mentors can monitor attendance, review progress, and assess candidate performance.

## Main Features

### Candidate Portal

- Daily attendance check-in
- Work location selection
- Automatic location capture
- Work From Home requests
- Daily work and learning logs
- Upload supporting evidence
- Report lateness or absence
- View weekly individual scorecards
- View mentor comments for each assessment category
- View group scorecards without private mentor comments

### Mentor Portal

- Monitor candidate attendance
- View weekly attendance trends
- View attendance by cohort
- Review Work From Home requests
- View candidate daily logs
- Monitor candidate status updates
- View candidates by cohort and group
- Complete weekly candidate scorecards
- Score candidates across multiple assessment categories
- Add individual mentor comments for each assessment category
- View automatically calculated overall performance scores

## Weekly Scorecard Categories

Candidates are assessed on:

- Attendance
- Communication
- Accountability
- Creativity & Ownership
- Project Delivery
- Technical Skills

Each category is scored from **1–5**.

The system automatically calculates the candidate's overall weekly performance percentage.

## Candidate Scorecard Privacy

Candidates can view:

- Their own individual scores
- Their mentor's comments
- Their overall weekly score
- Their group's scores

Mentor comments are private and are not displayed when viewing other group members' scorecards.
